# 共享原理
平台负责提供官方20x账号，拼车用户打开GPT官网后，输入平台提供的账号，GPT会往该邮箱地址发送一次性登陆验证码。
在拼车接玛平台使用提供的 车队编号+车队成员账号/车队成员密码 进行登陆后 ，即可获取验证码，如遇到获取验证码在冷却中，那么需要等过了冷却期才能继续获取(只要该拼车车队中有任意用户获取了验证码，就需要等冷却期过了才能继续获取验证码)。

# 使用注意事项
   1: 拼车IP地址强烈建议静态家宽IP；
   2: `GPT` 网页是会话记忆共享,不过可以通过项目隔离。
   3: GPT 5.6 Sol模型消耗token比较大，拼车注意合理使用(可以使用`codex` /`status` 查看消耗量，也可以在网页上进行查看)；
   4: 切勿将账号用于中转、单车票多人共享等违规操作，违规操作导致用量不足、降智、账号封禁等 后果自负。
   5: 拼车接玛平台提供的初始账号密码不可能错，不要手敲，复制账号密码登陆。
