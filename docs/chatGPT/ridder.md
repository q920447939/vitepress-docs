## 共享与登录方式

平台提供官方 20x 账号。拼车用户在 GPT 官网输入该账号后，GPT 会向对应邮箱发送一次性登录验证码。

<div class="guide-flow" role="list" aria-label="拼车登录流程">
  <div role="listitem">
    <span>01</span>
    <strong>登录官网</strong>
    <p>打开 GPT 官网，输入平台提供的官方 20x 账号。</p>
  </div>
  <div role="listitem">
    <span>02</span>
    <strong>接收验证码</strong>
    <p>GPT 向账号对应的邮箱发送一次性登录验证码。</p>
  </div>
  <div role="listitem">
    <span>03</span>
    <strong>平台取码</strong>
    <p>使用车队编号、成员账号和成员密码登录拼车接码平台，获取验证码。</p>
  </div>
</div>

::: info 验证码冷却
同一车队中任意成员获取验证码后，整个车队都需要等待冷却期结束才能再次取码。出现“获取验证码冷却中”时，请等待冷却结束后再操作。
:::

## 使用须知

<ol class="guide-rules">
  <li><strong>使用稳定网络</strong><span>拼车 IP 地址强烈建议使用静态家宽 IP。</span></li>
  <li><strong>隔离网页会话</strong><span>GPT 网页的会话记忆会在账号内共享，可以通过项目进行隔离。</span></li>
  <li><strong>合理分配用量</strong><span>GPT 5.6 Sol 模型消耗 Token 较多。可以在 Codex 中使用 <code>/status</code>，或在网页中查看消耗量。</span></li>
  <li><strong>遵守共享规则</strong><span>请勿将账号用于中转或将单个车票再次多人共享。违规操作可能导致用量不足、模型能力下降或账号封禁。</span></li>
  <li><strong>复制登录信息</strong><span>拼车接码平台提供的初始账号和密码已经配置完成，请复制后登录，避免手动输入错误。</span></li>
</ol>

### 手机验证

`Pro` 产品小概率会触发手机验证。需要验证时，可在卡网购买长效接码服务，一般为 5–6 元；请选择长效接码类型。

### 为什么不把账号放到中转站

- 部分用户需要直接使用网页；
- 自有中转业务与拼车账号混用后，出现模型能力下降或 IP 关联封号时更难排查；
- 接入中转会进一步增加账号封禁风险。

## 关于封号

所有渠道都存在封号可能。99% 的封号原因来自多人共享拼车账号、中转反代、逆向、渗透等违规操作。

如在使用过程中不幸封号，并且属于合理使用，可按教程提交申诉，有概率申请退回购买金额。
